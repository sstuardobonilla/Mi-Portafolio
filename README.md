# Portafolio Profesional — Sergio Stuardo Bonilla

Este repositorio contiene el código fuente del portafolio web profesional de **Sergio Stuardo Bonilla**, Técnico Programador y Desarrollador Full Stack Java Trainee.

El sitio ha sido diseñado desde cero aplicando conceptos UI/UX modernos, con estética modo oscuro (*Dark Aesthetic* inspirada en el ecosistema Apple/macOS).

## 🚀 Tecnologías Utilizadas

- **HTML5:** Estructura semántica accesible.
- **CSS3:** Sistema de diseño personalizado con variables nativas `:root`.
- **Bootstrap 5:** Sistema de rejilla responsive y componentes modal/offcanvas.
- **JavaScript Vanilla:** Lógica para interacciones de interfaz, navegación y validación.
- **Font Awesome:** Iconografía vectorial.
